# 🔍 Data Quality & Lineage for Finance Analytics Dashboard

## 📖 Project Story
In financial analytics, **data quality and lineage** are critical to ensure trust in decision-making. This project demonstrates how I built a reliable analytics pipeline using open financial data, with **data quality checks, lineage documentation, and a dashboard**.  

The key goal:  
> **Ensured analytics reliability by adding data tests & lineage before delivering insights.**

---

## 🛠️ Tools & Stack
- **dbt** → Data modeling, testing, and lineage graph  
- **Great Expectations** (or Soda) → Data quality checks  
- **Metabase / Streamlit** → Interactive dashboard  
- **Open Finance Dataset** → (e.g., stock prices, global economic indicators, interest rates)
